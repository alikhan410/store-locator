## App Description

### Main Description

**StoreTrail helps customers find nearby stores via an interactive map with directions and details.**

StoreTrail connects online shoppers to physical stores with a customizable store locator for Shopify. It features an interactive map, store details, and directions to help drive foot traffic. Merchants can manage multiple locations, apply advanced filters, and accept dealer submissions to expand. Built-in analytics track customer search behavior and store performance, offering insights to improve reach and engagement.

### Key Features List

1. **Interactive store locator** with Google Maps and real-time location search
2. **Dealer submission system** for adding new store locations with approval workflow
3. **Choropleth distribution map** showing store density by state (Pro plan)
4. **Bulk import/export** of store data using CSV for easy management (Basic+ plans)
5. **Advanced store management** with search, filters, and detailed store information
6. **Analytics dashboard** tracking customer searches and store performance (Pro plan)
